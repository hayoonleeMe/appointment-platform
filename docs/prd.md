# Appointment Platform PRD

## 제품 개요

> 1:1 또는 그룹 수업을 제공하는 개인 운영자가 예약 유형별 일정과 그룹 수업 회차를 등록하면 고객이 예약 페이지에서 가능한 선택지를 확인하고 비회원으로 예약할 수 있는 서비스.

## 문제

- 고객은 예약 가능 시간을 확인하기 위해 운영자에게 직접 문의해야 한다.
- 예약과 취소 요청이 카카오톡이나 전화 같은 개인 연락으로 이루어진다.
- 운영자는 예약 현황, 그룹 수업 정원, 빈 시간을 수동으로 관리해야 한다.
- 이 과정에서 예약 누락이나 일정 착오가 발생할 수 있다.

## 대상 사용자

### 운영자

고정된 시간 동안 1:1 서비스 또는 그룹 수업을 제공하고 예약 일정을 직접 관리하는 개인 운영자.

- PT 강사
- 과외·음악 레슨 강사
- 상담사
- 기타 1:1 서비스 또는 소규모 그룹 수업을 제공하는 개인 사업자

초기 버전에서는 여러 직원을 관리하는 사업장과 공간·좌석 단위 예약을 지원하지 않는다.

### 고객

운영자가 제공하는 1:1 서비스 또는 그룹 수업을 예약하려는 사용자.

## 핵심 사용자 흐름

예약 유형 선택 → 날짜 선택 → 1:1 시작 시각 또는 그룹 수업 회차 선택 → 이름·전화번호 입력 → 예약 확정

## MVP

### 운영자

- 운영자당 하나의 예약 페이지 제공
- 예약 유형 생성·비활성화
- 예약 유형별 반복 예약 가능 시간과 날짜 예외 설정
- 그룹 수업 회차 생성·취소
- 전체 예약 현황 조회와 예약 취소

### 고객

- 예약 페이지와 예약 유형 목록 조회
- 1:1 예약 가능한 시작 시간 조회
- 그룹 수업 회차와 잔여 좌석 조회
- 이름과 전화번호를 입력한 비회원 예약

## 핵심 제품 규칙

- 예약 유형마다 예약 방식, 소요 시간, 준비 시간, 반복 예약 가능 시간을 가진다. 1:1 예약 유형은 추가로 예약 시작 간격을 가진다.
- 예약 유형의 반복 예약 가능 시간은 요일별 하나 이상의 시간 구간으로 관리하며, 설정이 없는 요일은 예약을 받지 않는다.
- 특정 날짜에는 휴무 또는 시간 변경 예외를 설정할 수 있다.
- 같은 운영자의 예정 예약 세션 점유 시간은 예약 유형과 관계없이 겹칠 수 없다.
- 1:1 예약 가능 시간은 예약 유형의 최종 예약 가능 시간과 기존 예약 세션을 기준으로 동적으로 계산한다.
- 그룹 수업 회차는 정원을 가지며, 예약자가 없어도 예약 가능 시간을 점유한다.
- 예약 생성 시점에 예약 가능 여부 또는 잔여 좌석을 다시 확인한다.

## MVP 이후

- 운영자 회원가입과 로그인
- 예약 유형 수정
- 그룹 수업 반복 회차 생성과 회차 수정
- 고객 예약 조회·취소와 예약 변경
- 예약 알림과 취소 안내
- 고객 회원 기능
- 한 운영자의 여러 예약 페이지
- 운영자 공통 차단 일정
- 다중 직원, 공간·좌석 단위 예약
- 노쇼 정책

## 미결정 사항

- 고객 예약 변경을 직접 수정으로 지원할지, 취소 후 재예약으로 제한할지
- 고객 예약 취소 가능 시간 제한
- 예약·취소 안내를 제공할 채널
- 운영자가 고객을 대신해 예약을 등록할지
- 예약 유형 수정 시 기존 예약 처리와 고객 안내 방식
- 결제

## 성공 기준

운영자가 예약 유형별 예약 가능 시간과 날짜 예외를 등록하고, 1:1 예약 또는 그룹 수업 회차를 통해 고객이 별도 연락 없이 예약 하나를 생성할 수 있어야 한다.
