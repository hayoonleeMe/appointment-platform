# Appointment Platform PRD

## 제품 개요

> 1:1 서비스를 제공하는 개인 운영자가 운영 일정과 예약 서비스를 등록하면, 고객이 예약 페이지에서 가능한 시간을 확인하고 비회원으로 예약할 수 있는 서비스.

## 문제

- 고객은 예약 가능 시간을 확인하기 위해 운영자에게 직접 문의해야 한다.
- 예약과 취소 요청이 카카오톡이나 전화 같은 개인 연락으로 이루어진다.
- 운영자는 예약 현황과 빈 시간을 수동으로 관리해야 한다.
- 이 과정에서 예약 누락이나 일정 착오가 발생할 수 있다.

## 대상 사용자

### 운영자

고정된 시간 동안 1:1 서비스를 제공하고 예약 일정을 직접 관리하는 개인 운영자.

- PT 강사
- 과외·음악 레슨 강사
- 상담사
- 기타 1:1 서비스를 제공하는 개인 사업자

초기 버전에서는 여러 직원을 관리하는 사업장과 공간·좌석 단위 예약을 지원하지 않는다.

### 고객

운영자가 제공하는 1:1 서비스를 예약하려는 사용자.

## 핵심 사용자 흐름

서비스 선택 → 날짜 선택 → 예약 가능한 시간 선택 → 이름·전화번호 입력 → 예약 확정

## MVP

### 운영자

- 회원가입과 로그인
- 운영자당 하나의 예약 페이지 제공
- 예약 서비스 생성·비활성화
- 기본 운영 일정 설정
- 전체 예약 현황 조회와 예약 취소

### 고객

- 예약 페이지와 서비스 목록 조회
- 서비스·날짜·예약 가능한 시작 시간 조회
- 이름과 전화번호를 입력한 비회원 예약

## 핵심 제품 규칙

- 서비스마다 소요 시간, 준비 시간, 예약 시작 간격을 가진다.
- 운영 일정은 운영자 단위로 관리한다.
- 서로 다른 서비스라도 같은 운영자의 예약 점유 시간은 겹칠 수 없다.
- 예약 가능한 시간은 운영 일정, 서비스 설정, 기존 예약을 기준으로 동적으로 계산한다.
- 예약 생성 시점에 예약 가능 여부를 다시 확인한다.

## MVP 이후

- 예약 서비스 수정
- 고객 예약 조회·취소와 예약 변경
- 예약 알림과 취소 안내
- 고객 회원 기능
- 한 운영자의 여러 예약 페이지
- 특정 날짜 예외 일정
- 다중 직원, 공간·좌석 단위 예약
- 하루 여러 운영 구간과 노쇼 정책

## 미결정 사항

- 고객 예약 변경을 직접 수정으로 지원할지, 취소 후 재예약으로 제한할지
- 고객 예약 취소 가능 시간 제한
- 예약·취소 안내를 제공할 채널
- 운영자가 고객을 대신해 예약을 등록할지
- 예약 서비스 수정 시 기존 예약 처리와 고객 안내 방식
- 결제

## 성공 기준

운영자가 예약 페이지에 예약 서비스와 운영 일정을 등록하고, 고객이 별도 연락 없이 예약 하나를 생성할 수 있어야 한다.
