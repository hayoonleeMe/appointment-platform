# 요구사항

## 운영 일정

### REQ-SCHED-001 기본 운영 일정

운영자는 반복되는 기본 운영 일정을 요일별로 설정한다. 초기 MVP에서는 하루에 하나의 연속된 운영 구간만 설정할 수 있다.

모든 운영 일정과 예약 시간은 `Asia/Seoul` 시간대를 기준으로 한다.

예:

- 월요일 10:00 ~ 18:00
- 수요일 휴무
- 목요일 10:00 ~ 20:00

운영 일정은 예약 유형별이 아니라 운영자에게 속한다.

## 예약 유형

### REQ-TYPE-001 예약 유형 설정

운영자는 하나 이상의 예약 유형을 등록할 수 있다. 각 예약 유형에는 다음 정보를 둔다.

- 이름
- 예약 방식: `1:1` 또는 `그룹 수업`
- 소요 시간
- 서비스 종료 후 준비 시간
- 예약 시작 간격
- 활성 상태

비활성 예약 유형은 고객 예약 페이지 목록에서 숨기며 새 예약을 생성할 수 없다.

운영자는 등록된 예약 유형의 활성 상태를 변경할 수 있다.

예약 시작 간격은 1:1 고객이 선택할 수 있는 시작 시각 사이의 간격이며, 서비스 소요 시간과는 별개다.

## 예약 페이지

### REQ-PAGE-001 운영자 예약 페이지 제공

시스템은 운영자당 하나의 고객용 예약 페이지를 제공한다. 고객은 이 페이지에서 해당 운영자의 활성 예약 유형을 조회하고 예약을 진행할 수 있다.

## 그룹 수업 회차

### REQ-SESSION-001 그룹 수업 회차 생성

운영자는 그룹 수업 방식의 예약 유형에 대해서만 미래 시각의 예약 세션을 생성할 수 있다. 예약 세션에는 시작 시각과 정원을 지정한다.

예약 세션의 점유 시간은 예약 유형의 소요 시간과 준비 시간을 포함하며, 운영 일정 안에 있어야 한다. 같은 운영자의 예정된 예약 세션과 점유 시간이 겹치면 생성할 수 없다.

그룹 수업 회차는 날짜와 시각별로 수동 생성한다. 반복 회차 생성과 회차 수정은 MVP 이후 범위다.

### REQ-SESSION-002 그룹 수업 회차 취소

운영자는 예정된 그룹 수업 예약 세션을 취소할 수 있다. 세션을 취소하면 연결된 확정 예약도 모두 취소 상태가 되며, 세션의 점유 시간은 이후 예약 가능 시간 계산에서 제외한다.

예약·취소 안내는 MVP 이후 범위다.

## 예약 가능 선택지

### REQ-AVAIL-001 1:1 예약 가능 시간의 동적 계산

고객이 1:1 예약 유형과 날짜를 선택하면 시스템은 예약 가능한 시작 시각을 동적으로 계산한다. 미리 생성한 1:1 예약 슬롯은 저장하지 않는다.

계산에는 다음을 사용한다.

- 해당 요일의 기본 운영 일정
- 선택한 예약 유형의 소요 시간, 준비 시간, 예약 시작 간격
- 동일 운영자의 확정된 1:1 예약 세션과 예정된 그룹 수업 예약 세션

### REQ-AVAIL-002 1:1 시작 후보 시간

시작 후보는 해당 요일의 운영 구간 시작 시각부터 예약 시작 간격 단위로 생성한다.

예를 들어 운영 구간이 10:20 ~ 18:00이고 예약 시작 간격이 60분이면 시작 후보는 10:20, 11:20, 12:20 순서다.

### REQ-AVAIL-003 1:1 예약 가능 조건

1:1 시작 후보는 다음 조건을 모두 만족할 때만 예약 가능하다.

- 과거 시간이 아니다.
- 예약 유형의 소요 시간과 준비 시간을 포함한 전체 점유 시간이 운영 구간 안에 들어온다.
- 동일 운영자의 예정된 예약 세션 점유 시간과 겹치지 않는다.

### REQ-AVAIL-004 준비 시간과 충돌 판정

예약 유형의 시간이 50분이고 준비 시간이 10분이면 고객에게는 10:00 ~ 10:50으로 표시하더라도, 충돌 판단에서는 10:00 ~ 11:00을 점유한 것으로 본다. 예약 유형이 달라도 같은 운영자의 예약 세션 점유 시간은 겹칠 수 없다.

운영 구간 종료 전 남은 시간이 필요한 전체 시간보다 짧으면 서비스 시간을 줄이지 않고 해당 시작 후보를 제공하지 않는다.

### REQ-AVAIL-005 그룹 수업 회차 조회

고객이 그룹 수업 예약 유형과 날짜를 선택하면 시스템은 해당 날짜의 예정된 예약 세션을 보여 준다. 고객은 시작 시각, 종료 시각, 정원, 잔여 좌석을 확인할 수 있다.

잔여 좌석은 세션 정원에서 확정 예약 수를 뺀 값이다. 잔여 좌석이 없는 세션은 새 예약을 생성할 수 없다.

## 예약 생성

### REQ-BOOK-001 비회원 예약 정보

고객은 운영자의 예약 페이지에서 예약 유형 또는 예약 세션을 선택한 뒤 이름과 전화번호를 입력해 비회원으로 예약한다.

### REQ-BOOK-002 1:1 예약 생성

고객이 1:1 예약 유형과 예약 가능한 시작 시각을 선택하면, 서버는 예약 생성 시점에 유형이 활성 상태이고 해당 시간이 여전히 예약 가능한지 다시 검증한다.

검증에 성공하면 정원 1의 예약 세션과 확정 예약을 함께 생성한다.

### REQ-BOOK-003 그룹 수업 좌석 예약

고객이 예정된 그룹 수업 예약 세션을 선택하면, 서버는 예약 생성 시점에 예약 유형이 활성 상태이고 세션이 예정 상태이며 잔여 좌석이 있는지 다시 검증한다.

동시 요청에서도 확정 예약 수가 세션 정원을 초과하지 않도록 보장한다.

## 예약 현황

### REQ-RESERVATION-001 운영자 예약 현황 조회

운영자는 자신의 예약 현황을 조회할 수 있다. 예약 현황에는 확정된 예약과 취소된 예약을 포함한다.

## 예약 취소

### REQ-CANCEL-001 운영자 예약 취소

초기 MVP에서는 운영자만 확정된 예약을 취소할 수 있다. 1:1 예약을 취소하면 연결된 예약 세션도 취소되며, 취소된 예약과 예약 세션의 점유 시간은 이후 예약 가능 시간 계산에서 제외한다.

그룹 수업 예약의 개별 취소는 해당 좌석만 비우며 예약 세션은 예정 상태를 유지한다.

고객의 예약 조회·취소, 예약 변경, 취소 안내는 MVP 이후 범위다.
